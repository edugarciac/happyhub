## ADDED Requirements

### Requirement: Simplified event sidebar
The event dashboard sidebar SHALL show only Timeline, Invitados, Regalo, Música, Actividades, and Detalles as top-level sections, and SHALL be usable on mobile viewports without covering page content.

#### Scenario: Mobile visitor navigates sections
- **WHEN** a visitor on a narrow viewport opens an event
- **THEN** navigation SHALL be a bottom bar, not a persistent side rail
