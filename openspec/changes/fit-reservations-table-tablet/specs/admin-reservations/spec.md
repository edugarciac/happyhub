## MODIFIED Requirements

### Requirement: Reservations table fits tablets in landscape
The admin reservations table SHALL fit without horizontal scroll at 1194px viewport width and wider, showing reservation, event, payment, status and actions columns.

#### Scenario: iPad Pro 11" in landscape
- **WHEN** the admin opens the reservations page at 1194×834
- **THEN** the table SHALL have no horizontal scroll and all action buttons SHALL be visible
