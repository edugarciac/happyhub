# Homepage Redesign — Proposal

## Problem
The current homepage has all the right sections but lacks emotional impact, visual hierarchy, and conversion-focused storytelling. It reads like a feature list, not an experience.

## Goal
Redesign the homepage to create a "wow" first impression that emotionally connects with visitors celebrating a milestone event, drives bookings, and builds instant trust.

## Approach
Redesign all homepage sections with:
- Strong emotional narrative arc: Dream → Trust → Act
- Orange + Teal brand identity fully expressed (HappyHub logo colors)
- Premium-playful feel: warm, celebratory, confident
- New sections: TrustBar (social proof strip) + HowItWorks (3-step process)
- Improved section order for conversion

## Out of Scope
- Backend changes
- Other pages
- New features
