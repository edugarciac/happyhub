## Decisions

- **Avisar, no bloquear**: el admin puede haber pactado otra señal; bloquear dejaría la reserva sin confirmar aunque el cliente haya pagado.
- **Tolerancia de 0,005 €** para evitar falsos avisos por redondeo de céntimos.
- Solo para la señal: el resto se paga con enlaces de la web que calculan el importe exacto.
